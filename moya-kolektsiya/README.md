# Моя колекція · v0.1.0

Окремий персональний PWA у папці репозиторію «Мій графік». Не змінює основний застосунок.

## Реалізовано
- Вкладені папки, картки фігурок та фото
- 6 тем (фіолетова за замовчуванням)
- IndexedDB, локальна робота офлайн після встановлення
- Статуси, кількість, рік, два типи цін та журнал ручних змін ринкової ціни
- Статистика, чекліст відсутніх, сканування штрихкодів за підтримки браузера + ручний номер
- Експорт/імпорт повної JSON-копії, включно з фото
- Версія та поширення адреси PWA

## Обмеження v0.1.0
- Автоматичного імпорту повних серій та автоматичної ринкової оцінки **ще немає**: для цього необхідні належні каталожні API, ліцензії/дозволи та перевірка джерел. Зовнішня кнопка наразі відкриває пошук у браузері.
- Резервна копія зараз **JSON**, не ZIP. Вона включає всі фотографії як data URLs.
- Сканер базується на BarcodeDetector, якого немає в усіх браузерах.
- Дані на кожному пристрої незалежні, GitHub не синхронізує IndexedDB.

## Розгортання
Після увімкнення GitHub Pages для репозиторію за гілкою main і коренем сторінка доступна за адресою /miy-grafik/moya-kolektsiya/. Якщо Pages уже ввімкнено, оновлення має з'явитися після деплою. HTTPS потрібний для сканера.
