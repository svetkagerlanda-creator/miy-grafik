# Мій графік

Бірюзовий україномовний календар публікацій книг, створений у стилі «Мій репетитор».

## Можливості
- Тижневий календар з годинами від 00 до 23, перехід між тижнями.
- Книги з обкладинкою, кольором, початком, завершенням, часом і кількістю розділів.
- Автоматичне планування: щодня, через день, кожні N днів, конкретні дати.
- Попередження, якщо не вистачає дат для розділів.
- Ручне перенесення окремого розділу і позначення «Опубліковано».
- Екрани «Книги», «Сьогодні», «Статистика».
- Збереження у localStorage, імпорт/експорт JSON, експорт CSV.
- Мобільний адаптивний інтерфейс, базова підтримка встановлення як вебдодатка.

## Запуск на GitHub Pages
1. Створіть **публічний** репозиторій `miy-grafik` на GitHub (або приватний, якщо ваша конфігурація Pages це підтримує).
2. Завантажте в корінь репозиторію `index.html`, `sw.js`, `manifest.webmanifest`.
3. Відкрийте **Settings → Pages → Build and deployment → Deploy from a branch**, виберіть `main` і `/ (root)` → Save.
4. Відкрийте адресу, яку покаже GitHub Pages.

## Важливо
Дані зберігаються **тільки у браузері пристрою**, GitHub не синхронізує записи. Зберігайте резервну копію через ⋮ → Експорт JSON. Для синхронізації пристроїв потрібен окремий backend.
